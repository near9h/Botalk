──────────────────────────────────────────────────────────
§ 8 端到端时序（一句话聊天）
──────────────────────────────────────────────────────────

[Browser]  用户在 group 输入"分析这份文档里的关键条款"
   │  EventSource('/api/chat/stream?prompt=...')
   ▼
[Nginx]    终结 TLS，反代到 backend:8000，带 client_ip
   ▼
[Backend]  require_user → 加载 group/bots → msghub.run_group_discussion
   ▼
[msghub]   对每个 bot 轮次：
   ▼           ├─ language_detect → "zh"
   ▼           ├─ rag_retriever → local_retriever（BM25 + pgvector + RRF）→ top-5 chunks
   ▼           ├─ openai_compat.stream(...)
   ▼           │     ▼
   ▼           │  [NewAPI] → 上游 gpt-4o → 流式 token 回包
   ▼           ├─ 流式 SSE event: message / citation 推回 Browser
   ▼           ├─ 落 messages + audit_log
   ▼           └─ 检测 max_rounds / stop token → 退出
   ▼
[msghub]   全部 bot 完事 → _summarize → NewAPI → 📋 总结
   ▼
[Browser]  EventSource 关闭 / EventSource.onmessage 持续追加 UI

§ F3 KB 上传 + 解析
──────────────────────────────────────────────────────────

Browser POST /api/kb/{id}/documents (multipart)
  → Backend (kb.py)
      → require_user + _can_modify + mime + size 校验
      → 写文件 data/uploads/
      → attachments + kb_documents（status=pending）
      → asyncio.create_task(ingest_worker.run)
      → 立即返回 202 + doc_id

  ingest_worker.run（后台）：
    → status=parsing
    → 分支：
        mime=pdf → MinerU 解析
        mime=office → LibreOffice 转 PDF → MinerU 解析
    → kb_chunks 写 N 行（含 bbox_json + snippet）
    → zhipuai_embed → embedding 写回
    → status=ready
    → audit_log

  Frontend 轮询 GET /api/kb/{id}/documents/{doc_id} 直到 status=ready

  任何一步抛异常 → status=failed + 写 error 字段

──────────────────────────────────────────────────────────
§ F4 KB 检索 + 引用
──────────────────────────────────────────────────────────

query → local_retriever（BM25 + pgvector cosine）
  → RRF 融合 → top-k chunks
  → 注入 system prompt（参考资料 [n] snippet page）
  → LLM 输出含 [n]
  → 前端替换为 @@CITATION_n@@
  → markdown 渲染为 <button class="cite-chip">[1]</button>
  → 点击 chip → CitationDrawerContext.open(chunk_id)
  → GET /api/kb/{kb_id}/chunks/{chunk_id} → bbox + snippet
  → PDF.js 跳页 + 画红色 bbox 框

──────────────────────────────────────────────────────────
§ F6 审计落库
──────────────────────────────────────────────────────────

任意写操作（POST / PATCH / DELETE）
  ↓
Depends(audit_ctx)  ← 从 X-Real-IP / proxy_protocol 拿 client_ip
  ↓
业务 handler
  ↓
audit_service.log(
    action="kb.create",   # 动词.名词
    target_type="kb",
    target_id=str(kb.id),
    target_name=kb.name,
    detail={"foo":"bar"},
)
  ↓
audit_log 表
  ├─ id / actor / client_ip
  ├─ action / target_type / target_id
  ├─ detail (JSON)
  └─ created_at

运维 / 内审：
  SELECT * FROM audit_log ORDER BY created_at DESC LIMIT 50;
