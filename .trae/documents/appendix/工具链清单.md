# 工具链清单

## 代码 / 构建

| 工具 | 用途 | 入口 |
| --- | --- | --- |
| Next.js | 前端 | `frontend/` |
| FastAPI + uvicorn | 后端 | `backend/` |
| Alembic | 迁移 | `backend/alembic/` |
| Docker Compose | 容器编排 | `docker-compose.yml` |
| GitHub Actions | CI | `.github/workflows/ci.yml` |

## 数据 / 解析

| 工具 | 用途 | 容器 / 镜像 |
| --- | --- | --- |
| pgvector/pg16 | 持久化 + 向量 | `botgroup-postgres` |
| MinerU | PDF / Office 解析 | (外部镜像，按需部署) |
| LibreOffice headless | Office → PDF | 内置 `office_pdf.py` 调用 |
| zhipuai embedding | 向量生成 | API 调用 |
| NewAPI | LLM 网关 | `new-api` 容器 |
| RAGFlow | 可选 RAG 服务 | (可选) |

## 脚本

| 文件 | 用途 |
