# 术语表（Glossary）

| 术语 | 含义 |
| --- | --- |
| **Bot** | 一个 AI 代理（model + persona + temperature） |
| **Group** | 多个 Bot 的集合 + 调度策略 |
| **Persona** | bot 的人设系统提示词 |
| **KB** | Knowledge Base，知识库 |
| **Chunk** | KB 内文档的最小检索单元 |
| **Snippet** | chunk 的简短摘要，用于 RAG 上下文 |
| **bbox** | chunk 在 PDF 上的坐标（page + x/y/w/h） |
| **RAG** | Retrieval-Augmented Generation |
| **NewAPI** | OpenAI 兼容的 LLM 网关（外部依赖） |
| **MsgHub** | botgroup 自研编排器（见 ADR-0002） |
| **MSG** | Message，单条聊天消息 |
| **Run** | 一次任务的运行实例（含多轮） |
| **Audit log** | 全量操作审计表 |
| **auto / round_robin / manual** | 三种发言策略 |
| **max_rounds** | 单任务最大轮次 |
| **RAGFlow** | 可选的外部 RAG 服务（见 ADR-0004） |
| **scope=user / system** | KB 的可见性范围 |
| **is_public** | KB 是否对所有人可见 |
| **ragflow_dataset_id** | KB 在 RAGFlow 的数据集 ID |
| **public_id** | 外部 URL 用的不透明 ID（避免暴露内部自增 id） |
| **prior history** | 同一任务跨轮上下文（`msghub._load_prior_history`） |
| **summary（📋 总结）** | 任务结束时的总结消息 |
| **agent persona** | bot 的角色定位（"专业核保员"等） |
| **ReAct** | Reason+Act 模式（预留） |
