## 2. 立项理由（Business Case）

1. **业务问题**：单一 LLM 在多视角问题（核保、法律、文档）上无法同时兼顾准确性、风格与"对抗辩论"。
2. **方案**：把多个 bot（每个 = 一个模型 + 一段 persona）拉进同一个"群组"，由调度器按策略让它们互相回应。
3. **受益方**：
   - 业务组（核保 / 法务 / 产品）：一站式多模型评审
   - 平台组：统一接入 NewAPI（OpenAI 兼容），不锁厂商
   - 运维组：单机 Docker Compose 可交付，故障域清晰

---

## 3. 高层范围（High-Level Scope）

**包含（In-Scope）**

- 机器人 / 群组 / 消息 / 知识库 4 类核心实体 CRUD
- 多 LLM 调用（NewAPI 兼容协议）
- 三种发言策略：`auto` / `round_robin` / `manual`
- 流式输出（SSE）
- 知识库 RAG（上传 PDF / Word / Excel → 自动入库 → 引用）
- 用户 / 审计日志（满足 PMP 安全审计需求）
- 单机 Docker Compose 一键交付

**不包含（Out-of-Scope）**

- 跨集群多租户部署（仅单机单库）
- 移动 App / 微信小程序
- 模型微调 / 训练
- 商业计费
